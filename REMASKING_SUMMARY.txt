AARONSON WATERMARK REMASKING STRATEGIES - IMPLEMENTATION SUMMARY
================================================================================

WHAT WAS IMPLEMENTED:

Three new remasking strategies for Aaronson watermarking that control the
trade-off between watermark detectability and generation quality:

1. ORIGINAL (default): 
   - Uses only model's confidence for remasking
   - Best quality, moderate detectability
   
2. DUAL_GATE:
   - Requires both wm_conf >= tau_wm AND orig_conf >= tau_orig  
   - Parameters: tau_wm (default 0.2), tau_orig (default 0.01)
   - Balanced approach (recommended)
   
3. BLEND:
   - Combines: conf = lambda*wm_conf + (1-lambda)*orig_conf
   - Parameter: lambda (default 0.7, range 0-1)
   - Configurable trade-off
   
4. HARD_FAVOR:
   - Gives watermarked tokens high confidence (0.99)
   - Strongest detectability, highest risk to quality

FILES MODIFIED:

1. generate.py:
   - Modified apply_aaronson_gumbel_watermark() to return confidences
   - Added 4 new parameters to generate() function
   - Implemented 3 remasking strategies in generation loop

2. simple_generate.py:
   - Added 4 new command-line arguments
   - Updated generate() call with new parameters
   - Added strategy info to output

3. Documentation:
   - AARONSON_REMASKING_STRATEGIES.md: Comprehensive guide
   - REMASKING_SUMMARY.txt: This file

USAGE EXAMPLES:

# Balanced (recommended):
python simple_generate.py \
    --prompt "Your prompt" \
    --watermark_steps 100 \
    --aaronson_remasking_strategy dual_gate

# Strong watermark:
python simple_generate.py \
    --prompt "Your prompt" \
    --watermark_steps 150 \
    --aaronson_remasking_strategy blend \
    --aaronson_lambda 0.8

# Best quality:
python simple_generate.py \
    --prompt "Your prompt" \
    --watermark_steps 100 \
    --aaronson_remasking_strategy original

# Maximum detectability (risky):
python simple_generate.py \
    --prompt "Your prompt" \
    --watermark_steps 200 \
    --aaronson_remasking_strategy hard_favor

KEY BENEFITS:

1. Flexibility: Choose strategy based on your needs
2. Quality Protection: dual_gate and blend prevent very low-prob tokens
3. Detectability Control: Adjust parameters for stronger/weaker watermarks
4. Backward Compatible: Default 'original' maintains existing behavior

TECHNICAL DETAILS:

- Watermark confidence = model probability of watermark-chosen token
- Original confidence = model probability used for standard remasking
- Strategies modify the confidence scores used in topk selection
- Low confidence → token gets re-masked for another iteration
- High confidence → token gets committed (permanently kept)

Read AARONSON_REMASKING_STRATEGIES.md for detailed documentation.
